# บวกหนึ่ง (Incrementer)

## ชิ้นนี้คืออะไร

ให้ค่า **y = a + 1** ถ้า a = 255 จะได้ 0 เพราะบัสมีแค่ 8 บิต ผลจึง **วนกลับ (overflow)** เหมือนมาตรวัดระยะทางของรถที่หมุนครบรอบ

## สิ่งที่มีให้ใช้

Half Adder, Full Adder, ตัวแยก/รวม bus และ **ค่าคงที่ 0 / 1**

## ในคอมพิวเตอร์จริง

ตัวนับโปรแกรม (Program Counter) ใช้วงจรนี้เลื่อนไปคำสั่งถัดไปทุกจังหวะนาฬิกา
