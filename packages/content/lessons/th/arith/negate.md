# เลขติดลบ (Negator)

## ชิ้นนี้คืออะไร

บัสมีแต่ 0 กับ 1 ไม่มีเครื่องหมายลบ คอมพิวเตอร์จึงตกลงกันว่าจะ **อ่าน** 8 บิตแบบมีเครื่องหมาย (signed) ด้วยวิธี **two's complement (ส่วนเติมเต็มสอง)**

- บิตบนสุด (บิต 7) เป็น 1 แปลว่าติดลบ
- **−a = (กลับทุกบิตของ a) + 1**

| บิต | อ่านแบบไม่มีเครื่องหมาย | อ่านแบบมีเครื่องหมาย |
| --- | --- | --- |
| 00000001 | 1 | 1 |
| 01111111 | 127 | 127 |
| 10000000 | 128 | −128 |
| 11111110 | 254 | −2 |
| 11111111 | 255 | −1 |

ข้อดีคือ **บวกเลขติดลบด้วยตัวบวกเดิมได้เลย** เช่น 5 + (−1) = 00000101 + 11111111 = 00000100 = 4 (ตัวทดที่ล้นออกไปทิ้งได้)

## โจทย์

สร้างวงจรที่ให้ **y = −a** แผงขาออกทางขวาจะแสดงทั้งสองแบบ เช่น `255 · มีเครื่องหมาย −1`

## ในคอมพิวเตอร์จริง

CPU แทบทุกตัวในโลกใช้ two's complement เพราะวงจรบวกตัวเดียวทำได้ทั้งบวกและลบ ด่านถัดไปจะใช้ข้อนี้สร้างวงจรลบ
