# Register 1 บิต

## ชิ้นนี้คืออะไร

D Flip-Flop รับค่าใหม่ *ทุก* จังหวะนาฬิกา แต่ register ใน CPU ต้องเลือกได้ว่าจังหวะไหนจะเก็บค่า ขา **load** ทำหน้าที่นี้

- **load = 1:** ตอนนาฬิกาเดิน เก็บค่า **in**
- **load = 0:** คงค่าเดิมไว้ ไม่ว่า in จะเป็นอะไร

## สิ่งที่มีให้ใช้

ชิ้นตรรกะทั้งหมด (รวม MUX) และ D Flip-Flop

## ในคอมพิวเตอร์จริง

register ทุกตัวของ Z8 (A, B, C, D, SP, PC, flags) คือชิ้นนี้หลายตัวเรียงกัน
