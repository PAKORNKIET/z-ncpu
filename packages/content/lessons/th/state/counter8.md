# ตัวนับ 8 บิต (Counter)

## ชิ้นนี้คืออะไร

**q** เพิ่มทีละ 1 ทุกจังหวะนาฬิกา: 0, 1, 2, … 255 แล้ววนกลับเป็น 0 ถ้า **reset = 1** จังหวะถัดไป q จะเป็น 0

## โจทย์

ทดสอบเดินนาฬิกาหลายร้อยจังหวะ (ดูคอลัมน์ "นาฬิกา" ในตาราง) ตอนลองเองกดปุ่ม ⏱ แล้วดู q เพิ่มขึ้น

## ในคอมพิวเตอร์จริง

ตัวนับโปรแกรม (Program Counter) คือตัวนับแบบนี้ที่เพิ่มฟังก์ชันกระโดด จะได้สร้างในบท Control
