# ตัวชี้ Stack (Stack Pointer)

## ชิ้นนี้คืออะไร

**Stack** คือพื้นที่ใน RAM ที่ใช้เก็บค่าแบบ "เข้าทีหลัง ออกก่อน" เหมือนจานที่วางซ้อนกัน **SP** เก็บ address ของค่าบนสุด ใน Z8 stack เริ่มที่ 0xF0 และ **โตลงล่าง**

| op | SP ถัดไป | ใช้ตอน |
| --- | --- | --- |
| 0 | เท่าเดิม | คำสั่งทั่วไป |
| 1 | SP − 1 | PUSH, CALL (เขียนค่าที่ address SP − 1) |
| 2 | SP + 1 | POP, RET (อ่านค่าที่ address SP) |

ขา **down** ส่งค่า SP − 1 ออกมาตลอดเวลา เพราะ PUSH ต้องใช้ address นี้ในจังหวะเดียวกับที่ SP กำลังจะลดลง ส่วน **reset** ทำให้ SP = 0xF0 ค่าวนรอบ 8 บิตเหมือน register อื่น (0xFF + 1 = 0x00)

## ในคอมพิวเตอร์จริง

stack ทำให้เรียกฟังก์ชันซ้อนกันได้: CALL เก็บ address ที่ต้องกลับไว้บน stack และ RET หยิบออกมา ฟังก์ชันที่เรียกตัวเอง (recursion) ก็ทำงานด้วยกลไกนี้ ถ้าเรียกซ้อนลึกเกินไปจน stack ทับข้อมูลอื่นจะเกิด **stack overflow**
