# จอ 7 ส่วน (7-segment)

## ชิ้นนี้คืออะไร

จอตัวเลขในนาฬิกาดิจิทัลหรือเครื่องคิดเลขมีขีด 7 ขีดชื่อ **a ถึง g** เปิดขีดต่างกันแล้วเป็นเลขต่างกัน ด่านนี้แปลงเลข 4 บิต (0–15) เป็นรูปแบบไฟ 7 บิต (**seg** บิต 0 = a, บิต 6 = g) ให้แสดง 0–9 และ A–F

| ขีด | ตำแหน่ง |
| --- | --- |
| a | บน |
| b | ขวาบน |
| c | ขวาล่าง |
| d | ล่าง |
| e | ซ้ายล่าง |
| f | ซ้ายบน |
| g | กลาง |

ทางขวามีจอ 7 ส่วนจริงให้ดูผลทันที เลข 0 เปิดทุกขีดยกเว้น g, เลข 1 เปิดแค่ b กับ c

## ในคอมพิวเตอร์จริง

CPU Z8 ส่งค่าไปที่ address 0xF2 แล้ววงจรแบบนี้แปลงเป็นตัวเลขบนจอ เป็นอุปกรณ์แสดงผลชิ้นแรกที่ CPU จะใช้ใน M3
