# ชุด Register (Register file)

## ชิ้นนี้คืออะไร

Z8 มี register ใช้งานทั่วไป 4 ตัวคือ **A, B, C, D** (หมายเลข 0–3) คำสั่งอย่าง `ADD A, B` ต้องอ่านสองตัวพร้อมกันและเขียนผลกลับหนึ่งตัว Register file จึงมี

- **ทางอ่าน 2 ทาง**: x = register หมายเลข rd, y = register หมายเลข rs (อ่านได้ทันที ไม่ต้องรอ clock)
- **ทางเขียน 1 ทาง**: ถ้า write = 1 ตอน clock ขาขึ้น register หมายเลข rd จะรับค่า in
- **reset**: ถ้า reset = 1 ตอน clock ขาขึ้น ทั้ง 4 ตัวกลายเป็น 0 (ชนะ write)
- **a, b, c, d**: ค่าในแต่ละตัว ต่อออกมาให้ดูตอนดีบัก

สังเกตว่า rd ใช้ทั้งเลือกตัวที่อ่านออกทาง x และตัวที่เขียน เพราะคำสั่ง Z8 แบบ `ADD rd, src` อ่าน rd แล้วเขียนผลกลับที่ rd เดิม

## ในคอมพิวเตอร์จริง

CPU ทุกตัวมี register file เป็นหน่วยความจำที่เร็วที่สุดในเครื่อง ARM 64 บิตมี 31 ตัว x86-64 มี 16 ตัว CPU สมัยใหม่อ่านได้พร้อมกันหลายทางเพื่อทำหลายคำสั่งในจังหวะเดียว
