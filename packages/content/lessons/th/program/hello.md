# แสดงเลข 42

## โปรแกรมแรกบน CPU ของคุณ

CPU ที่ต่อเองจาก NAND อ่านคำสั่งทีละคำจาก ROM บทนี้ไม่ต้องต่อวงจรแล้ว แต่ **เขียนโปรแกรม** ภาษา assembly ของ Z8 ให้ CPU ทำงานแทน

| คำสั่ง | ความหมาย |
| --- | --- |
| `MOV A, 42` | ใส่ค่า 42 ลง register A |
| `STORE [OUT], A` | เขียนค่าใน A ไปที่ address 0xF0 ซึ่งต่อกับจอตัวเลข |
| `HALT` | หยุด CPU |

`OUT` เป็นชื่อที่ assembler รู้จักอยู่แล้ว (= 0xF0) จอไม่ใช่ RAM แต่ CPU คุยกับมันด้วย STORE แบบเดียวกัน เรียกว่า **memory-mapped I/O**

ทุกโปรแกรมในบทนี้ต้องจบด้วย `HALT` เกมจะรันบน CPU ของคุณจนถึง HALT แล้วดูว่าจอแสดงอะไร
