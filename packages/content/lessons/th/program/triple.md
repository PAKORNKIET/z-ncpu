# ฟังก์ชัน: คูณ 3 ด้วย CALL

เขียน **ฟังก์ชัน** `triple` ที่ทำให้ A = A × 3 (ตัดเหลือ 8 บิต) แล้วเรียกใช้สองครั้ง:

1. อ่านสวิตช์ใส่ A แล้ว `CALL triple` แสดงผลบนจอ (= x × 3)
2. `CALL triple` อีกครั้ง แล้วแสดงผลบน LED (= x × 9)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `CALL triple` | จำ address ของคำสั่งถัดไปไว้บน stack แล้วกระโดดไปที่ triple |
| `RET` | หยิบ address นั้นออกจาก stack แล้วกลับไปทำต่อ |

ถ้าฟังก์ชันต้องใช้ register อื่นช่วย ให้ PUSH เก็บค่าเดิมไว้ตอนเข้า แล้ว POP คืนก่อน RET

## ในคอมพิวเตอร์จริง

ทุกครั้งที่โปรแกรมเรียกฟังก์ชัน CPU ทำแบบนี้ ถ้าฟังก์ชันเรียกตัวเองลึกเกินไป stack จะเต็ม เกิด **stack overflow**
