# ค่าที่มากกว่า

อ่านเลขสองตัวจาก **สวิตช์** (`LOAD A, [SW]`) และ **คีย์บอร์ด** (`LOAD B, [KEY]`) แล้วแสดงตัวที่มากกว่าบนจอ (ถ้าเท่ากันแสดงตัวนั้น)

เกมทดสอบหลายกรณีด้วยค่าขาเข้าต่างกัน โปรแกรมจึงต้องถูกทุกกรณี

`CMP A, B` คำนวณ A + NOT B + 1 แบบเดียวกับ SUB ดังนั้น **C = 1 แปลว่า A ≥ B** (แบบไม่มีเครื่องหมาย)

## ในคอมพิวเตอร์จริง

CPU ARM ก็ใช้กติกา C เดียวกันนี้ คำสั่งอย่าง `if (a >= b)` จึงกลายเป็น CMP ตามด้วยกระโดดตาม C
