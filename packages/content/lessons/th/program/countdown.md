# นับถอยหลัง 5 ถึง 0

## loop กับ flags

ให้จอแสดง 5, 4, 3, 2, 1, 0 ตามลำดับแล้วหยุด เขียน `STORE` หกครั้งก็ได้ แต่ลองใช้ **loop** แทน

คำสั่ง ALU ทุกตัวตั้ง **flags** ให้: Z = ผลเป็น 0, N = ผลติดลบ (บิต 7 เป็น 1), C = มีตัวทด คำสั่งกระโดดแบบมีเงื่อนไขใช้ flags เหล่านี้ตัดสิน

| คำสั่ง | กระโดดเมื่อ |
| --- | --- |
| `JZ x` / `JNZ x` | Z = 1 / Z = 0 |
| `JN x` | N = 1 |
| `JC x` | C = 1 |
| `JMP x` | เสมอ |

ใช้ **label** ตั้งชื่อตำแหน่งที่จะกระโดดไป เช่น `loop:` แล้วเขียน `JMP loop`

## ในคอมพิวเตอร์จริง

`for` และ `while` ในภาษาโปรแกรมทุกภาษาถูกแปลงเป็น "คำนวณ → ดู flag → กระโดด" แบบนี้เสมอ
