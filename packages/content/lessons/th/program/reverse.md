# กลับลำดับด้วย stack

ให้ x = ค่าจากสวิตช์ แล้วจอต้องแสดง **x + 2, x + 1, x** ตามลำดับ

เงื่อนไข: คำนวณ x, x + 1, x + 2 ตามลำดับจากน้อยไปมาก แล้วใช้ **stack** กลับลำดับ

| คำสั่ง | ทำอะไร |
| --- | --- |
| `PUSH A` | วาง A ไว้บนสุดของ stack (SP ลดลง 1) |
| `POP B` | หยิบค่าบนสุดออกมาใส่ B (SP เพิ่ม 1) |

ค่าที่ PUSH ทีหลังจะถูก POP ออกมาก่อน (เข้าทีหลังออกก่อน) เหมือนจานที่วางซ้อนกัน

## ในคอมพิวเตอร์จริง

ปุ่ม Undo ในโปรแกรมต่างๆ ก็เก็บประวัติเป็น stack: ทำอะไรล่าสุด ถูกย้อนก่อน
