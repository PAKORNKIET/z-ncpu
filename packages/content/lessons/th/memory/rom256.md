# ROM256

## ชิ้นนี้คืออะไร

256 คำ (addr 8 บิต, data 4,096 บิต) คือหน่วยความจำโปรแกรมทั้งหมดของ Z8 ใช้ NAND ราว 16,000 ตัว แผงค่าคงที่ที่ยังไม่ได้ใส่โปรแกรมเป็น 0 ทุกบิต ซึ่งคือคำสั่ง NOP (ไม่ทำอะไร) ของ Z8

## ในคอมพิวเตอร์จริง

แก้โปรแกรมแค่เปลี่ยนสวิตช์บนแผง วงจร ROM ไม่เปลี่ยน CPU จึงไม่ต้องทดสอบใหม่ทุกครั้งที่แก้โปรแกรม
