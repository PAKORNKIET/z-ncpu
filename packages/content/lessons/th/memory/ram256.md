# RAM256

## ชิ้นนี้คืออะไร

256 ช่อง (addr 8 บิต) คือหน่วยความจำข้อมูลของ CPU Z8 ทั้งหมด สร้างจาก **RAM64 สี่ตัว**

## ขนาด

วงจรนี้ใช้ NAND ราว 36,000 ตัว ระบบจึงจำลองด้วย Fast Mode ให้อัตโนมัติ ลองเปิด X-Ray ดูชั้นข้างใน: RAM256 → RAM64 → RAM8 → Register → Flip-Flop → NAND

## ในคอมพิวเตอร์จริง

ช่อง 0–239 ใช้เก็บข้อมูลและ stack ส่วนช่อง 240 ขึ้นไป CPU ส่งไปที่อุปกรณ์ เช่นจอแสดงตัวเลขและ LED ซึ่งจะต่อในบทถัดไป
