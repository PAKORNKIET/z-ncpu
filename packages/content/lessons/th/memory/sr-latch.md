# SR Latch: วงจรจำค่าแรก

## ชิ้นนี้คืออะไร

วงจรทุกตัวที่ผ่านมาให้ผลตามขาเข้า *ตอนนี้* เท่านั้น แต่คอมพิวเตอร์ต้อง **จำ** ได้ด้วย **SR Latch (แลตช์)** จำค่าได้หนึ่งบิต

- **s = 1** (set) ทำให้ q เป็น 1
- **r = 1** (reset) ทำให้ q เป็น 0
- **s = 0 และ r = 0** คงค่า q เดิมไว้ คือ *จำ* ค่าล่าสุด
- ห้ามให้ s และ r เป็น 1 พร้อมกัน

## สิ่งที่มีให้ใช้

NAND, NOT, AND และ OR

## โจทย์

ด่านนี้ทดสอบเป็น **ลำดับเวลา** ไม่ใช่ตาราง: ตั้งค่าทีละขั้นแล้วดูว่า q จำค่าถูกไหม ความลับคือ **การป้อนกลับ (feedback)** คือต่อขาออกวนกลับไปเป็นขาเข้า ระบบรองรับวงจรที่วนแบบนี้ ไม่ต้องกลัว

## ในคอมพิวเตอร์จริง

ทุกบิตใน register และหน่วยความจำของ CPU ที่จะสร้าง เริ่มจากวงจรวนกลับแบบนี้
