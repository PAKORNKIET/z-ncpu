# D Flip-Flop: จำค่าตอนนาฬิกาเดิน

## ชิ้นนี้คืออะไร

คอมพิวเตอร์ทำงานเป็นจังหวะตาม **สัญญาณนาฬิกา (clock)** ที่สลับ 0, 1, 0, 1 ไปเรื่อยๆ **D Flip-Flop** รับค่า d เข้าไปเก็บ *เฉพาะตอนที่ clk เปลี่ยนจาก 0 เป็น 1* (ขอบขาขึ้น) เท่านั้น ช่วงอื่น d จะเปลี่ยนอย่างไร q ก็ไม่เปลี่ยน

ทำไมต้องเป็นแค่ "ตอนเปลี่ยน": ถ้าวงจรรับค่าตลอดช่วงที่ clk = 1 (แบบ D Latch) ค่าใหม่อาจวิ่งวนกลับมาเปลี่ยนตัวเองซ้ำหลายรอบในจังหวะเดียว

## สิ่งที่มีให้ใช้

NAND, NOT, AND, OR, SR Latch และ **D Latch**

## โจทย์

ในการทดสอบ "⏱" คือส่งสัญญาณนาฬิกาหนึ่งจังหวะ (0 → 1 → 0) ตอนลองเองที่แผงขวามีปุ่ม **⏱ เดินนาฬิกา 1 จังหวะ** หรือจะกดสวิตช์ clk เองก็ได้

## ในคอมพิวเตอร์จริง

Register, ตัวนับโปรแกรม (Program Counter) และหน่วยความจำทุกบิตของ CPU Z8 สร้างจาก D Flip-Flop เป็นด่านสุดท้ายของ M1 ก่อนเริ่มสร้างส่วนประกอบของ CPU
