# ROM8 + แผงค่าคงที่

## ชิ้นนี้คืออะไร

**ROM (Read-Only Memory)** เก็บโปรแกรมของ CPU: CPU บอก **addr** แล้วได้ **คำสั่ง 16 บิต** ที่อยู่ตรงนั้นออกมาทาง **out**

โปรแกรมมาจาก **แผงค่าคงที่ (constant panel)** ซึ่งเหมือนแผงสวิตช์ 0/1 ของคอมพิวเตอร์ยุคแรก assembler จะตั้งสวิตช์ให้ตามโปรแกรมที่เขียน แผงส่งข้อมูลทั้งหมดเข้า ROM ทาง **มัดสาย (bundle) data**

- data กว้าง 128 บิต = 8 คำ × 16 บิต
- คำที่ 0 อยู่ที่บิต 0–15, คำที่ 1 อยู่ที่บิต 16–31 ไปเรื่อยๆ

## โจทย์

ด่านนี้ต่อแผงค่าคงที่ที่มีข้อมูลตัวอย่างเข้าขา data ให้แล้ว ตารางทางขวาแสดงว่าแต่ละช่องมีค่าอะไร ลองเปลี่ยน addr แล้วดูว่า out ตรงกับตารางไหม การทดสอบจะใส่ข้อมูลสุ่มสองชุดแล้วอ่านทุก addr

## ในคอมพิวเตอร์จริง

ROM ไม่มีวงจรเขียนเลย มีแค่ "เลือกคำ" ROM ที่สร้างจึงเล็กกว่า RAM ขนาดเท่ากันมาก
