# ALU 8 บิต

## ชิ้นนี้คืออะไร

**ALU (หน่วยคำนวณและตรรกะ)** คือหัวใจที่คำนวณของ CPU รับ **a**, **b** และรหัสคำสั่ง **op** 3 บิต แล้วให้ผล **y** พร้อม flags สามตัว

| op | คำสั่ง | y | c |
| --- | --- | --- | --- |
| 000 | ADD | a + b | ตัวทดออก |
| 001 | SUB | a − b | ตัวทดของ a + NOT b + 1 |
| 010 | AND | a AND b | 0 |
| 011 | OR | a OR b | 0 |
| 100 | XOR | a XOR b | 0 |
| 101 | NOT | NOT a | 0 |
| 110 | (ไม่ใช้) | 0 | 0 |
| 111 | CMP | a − b (เหมือน SUB) | เหมือน SUB |

- **z (Zero):** 1 เมื่อ y = 0
- **n (Negative):** บิต 7 ของ y
- **c (Carry):** ตอนลบ c = 1 แปลว่า a ≥ b (คิดแบบไม่มีเครื่องหมาย)

## โจทย์

ไม่ต้องคิดว่าคำสั่งไหนกำลังทำ ให้ **คำนวณทุกแบบพร้อมกัน** แล้วเลือกผลด้วย op วิธีนี้คือวิธีที่ CPU จริงทำ ขาเข้ารวม 19 บิต ทดสอบแบบกรณีขอบ + สุ่ม 2,000 แบบ

## ในคอมพิวเตอร์จริง

op ตรงกับเลข func ของคำสั่งกลุ่ม 01 ใน Z8 พอดี ตัวถอดรหัสคำสั่งจึงส่ง 3 บิตนี้ตรงเข้า ALU ได้เลย ส่วน CMP คำนวณเหมือน SUB แต่ CPU จะเก็บแค่ flags ไม่เก็บผล
