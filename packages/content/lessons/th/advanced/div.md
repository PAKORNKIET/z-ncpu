# หารเอาผลหารและเศษ

ตัวตั้งมาจาก **สวิตช์** (0xF8) ตัวหารมาจาก **คีย์บอร์ด** (0xFA) ให้จอแสดง **ผลหาร** และ LED แสดง **เศษ**

เช่น 100 ÷ 7 ได้ 14 เศษ 2

## หารคือการลบซ้ำ

ลบตัวหารออกจากตัวตั้งไปเรื่อยๆ จนลบไม่ได้แล้ว จำนวนครั้งที่ลบได้คือผลหาร ที่เหลือคือเศษ

ตรวจว่ายังลบได้ด้วย `CMP A, B` ถ้า A ≥ B ธง C = 1

ด่านนี้รับประกันว่าตัวหารไม่เป็น 0 ลองคิดดูว่าถ้าเป็น 0 โปรแกรมจะเป็นอย่างไร

## ในคอมพิวเตอร์จริง

การหารเป็นคำสั่งที่ช้าที่สุดใน CPU หลายรุ่น และการหารด้วย 0 ทำให้ CPU จริงหยุดโปรแกรมด้วย exception
