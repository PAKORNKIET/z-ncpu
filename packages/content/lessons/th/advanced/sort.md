# เรียงลำดับด้วย bubble sort

ให้ x = ค่าจากสวิตช์ (เป็นเลขคี่เสมอ) สร้างเลข 6 ตัว: **x, 2x, 3x, 4x, 5x, 6x** โดยตัดเหลือ 8 บิต (เกิน 255 ให้วนกลับ ซึ่ง ADD ทำให้อยู่แล้ว) แล้วให้จอแสดงทั้ง 6 ตัว **เรียงจากน้อยไปมาก**

เช่น x = 0x35 (53): ได้ 53, 106, 159, 212, 9, 62 เรียงแล้วเป็น 9, 53, 62, 106, 159, 212

## Bubble sort

ไล่เทียบเลขที่อยู่ติดกันทีละคู่ ถ้าตัวหน้ามากกว่าให้สลับ หนึ่งรอบจะดันตัวที่มากที่สุดไปอยู่ท้ายสุด (เหมือนฟองอากาศลอยขึ้น) ทำซ้ำ 5 รอบก็เรียงครบ 6 ตัว

ใช้ register เป็น **ตัวชี้** ช่องใน RAM: `LOAD A, [C]` อ่านช่องที่ C ชี้ แล้ว `ADD C, 1` ไปช่องถัดไป

## ในคอมพิวเตอร์จริง

bubble sort เข้าใจง่ายแต่ช้าเมื่อข้อมูลเยอะ (เทียบประมาณ n² ครั้ง) โปรแกรมจริงจึงใช้วิธีที่เร็วกว่า เช่น quicksort หรือ merge sort ลองนับดูว่าด่านนี้ใช้กี่ cycle
