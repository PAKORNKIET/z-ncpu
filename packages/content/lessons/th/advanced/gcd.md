# ห.ร.ม. แบบยูคลิด

ให้จอแสดง **ห.ร.ม.** (ตัวหารร่วมมาก) ของค่าจากสวิตช์กับค่าจากคีย์บอร์ด ทั้งสองค่าไม่เป็น 0

## วิธีของยูคลิด

อัลกอริทึมนี้มีอายุกว่า 2,300 ปี: ถ้า a > b ห.ร.ม.(a, b) เท่ากับ ห.ร.ม.(a − b, b) ลบตัวใหญ่ด้วยตัวเล็กไปเรื่อยๆ จนทั้งสองเท่ากัน ค่านั้นคือคำตอบ

เช่น (48, 18) → (30, 18) → (12, 18) → (12, 6) → (6, 6) ได้ 6

ใช้ `CMP A, B` ครั้งเดียวได้ทั้งสองข้อมูล: **Z = 1** แปลว่าเท่ากัน **C = 1** แปลว่า A ≥ B
