# โบนัส: เพิ่มคำสั่ง SHR ให้ CPU

## ออกแบบ CPU ของตัวเอง

ที่ผ่านมาคุณทำ CPU ตามชุดคำสั่ง (ISA) ของ Z8 ที่กำหนดไว้แล้ว ด่านนี้คุณจะ **เพิ่มคำสั่งใหม่เอง** ตอนออกแบบ Z8 เราเว้นกลุ่มคำสั่ง `11` ไว้ให้ทั้งกลุ่ม (func 000–111 รวม 8 ช่อง) ทุกช่องตอนนี้ทำงานเหมือน NOP

คำสั่งแรกคือ **SHR rd** (shift right) เลื่อนทุกบิตของ rd ไปทางขวา 1 ตำแหน่ง บิตบนสุดเติม 0 ซึ่งก็คือ **หารสองปัดเศษทิ้ง** เช่น 0x96 (150) กลายเป็น 0x4B (75)

| | |
| --- | --- |
| รูปแบบ | `SHR rd` |
| รหัสเครื่อง | group = 11, func = 000, rd ที่บิต 10–9 |
| สูตร | `rd = rd >> 1` |
| flags | ไม่เปลี่ยน |

## เริ่มจาก CPU ของคุณ

ด่านนี้สร้างชิ้นใหม่ชื่อ **CPU Z8+** โดยคัดลอกวงจรจาก CPU ที่คุณต่อในบทที่ 7 มาให้ CPU เดิมไม่ถูกแก้ ด่านในบท 8 และ 9 จึงยังผ่านเหมือนเดิม

สิ่งที่ต้องเพิ่มมีสามส่วน

1. **ตัวเลื่อนบิต** แยก rd ออกเป็นบิตแล้วรวมกลับแบบเยื้องไปหนึ่งช่อง ไม่ต้องใช้ NAND เลยสักตัว
2. **ตรวจว่าเป็น SHR** จากบิต 15–11 ของคำสั่ง
3. **สัญญาณควบคุม** เมื่อเป็น SHR ให้เขียน register และเลือกผลจากตัวเลื่อนบิตไปเขียนกลับ

## ทดสอบอย่างไร

เหมือนด่าน CPU: เทียบทุกขาดีบักกับ emulator ทุก cycle แต่ emulator ของด่านนี้รู้จัก SHR จากสูตร `rd = rd >> 1` และยังรันโปรแกรมทดสอบเดิมของบทที่ 7 ด้วย เพื่อให้แน่ใจว่าคำสั่งเดิมไม่พัง

## หลังผ่านด่าน

- หน้า **คอมพิวเตอร์** เลือก CPU Z8+ แล้วเขียนโปรแกรมที่ใช้ SHR ได้
- หน้า **สนามทดลอง** มีส่วน **ISA ของฉัน** เพิ่มคำสั่งของตัวเองได้อีก (เช่น INC, SHL, JNC) แค่ตั้งชื่อ เลือก func และเขียนสูตร แล้วกลับมาต่อวงจรเพิ่มในด่านนี้ หน้าคอมพิวเตอร์มีปุ่มเทียบกับ emulator ทีละ cycle ให้ตรวจ

## ในคอมพิวเตอร์จริง

CPU จริงก็เพิ่มคำสั่งใหม่แบบนี้: x86 เพิ่ม MMX, SSE และ AVX ทีละชุด ส่วน RISC-V เว้นช่องรหัสคำสั่งไว้ให้ผู้ผลิตเพิ่มคำสั่งของตัวเอง (custom extension) ตั้งแต่แรก แบบเดียวกับกลุ่ม 11 ของ Z8
