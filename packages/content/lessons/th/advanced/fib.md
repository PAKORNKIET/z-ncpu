# ลำดับฟีโบนัชชี

ลำดับฟีโบนัชชีเริ่มจาก 1, 1 แล้วตัวถัดไปคือผลบวกของสองตัวก่อนหน้า: 1, 1, 2, 3, 5, 8, 13, …

ให้จอแสดงทุกตัวที่ **ไม่เกิน 255** ตามลำดับ แล้ว HALT

จอนับเฉพาะตอนที่ค่าเปลี่ยน เลข 1 ตัวที่สองจึงไม่นับซ้ำ จอต้องแสดง **1, 2, 3, 5, 8, …, 233**

## รู้ได้อย่างไรว่าเกิน 255

register มีแค่ 8 บิต ถ้าผลบวกเกิน 255 ค่าจะวนกลับ (เช่น 144 + 233 = 377 กลายเป็น 121) แต่ ALU จะตั้งธง **C (carry)** ให้เป็น 1 บอกว่าบวกแล้วล้น ใช้ `JC` กระโดดออกจากลูปได้เลย

## ในคอมพิวเตอร์จริง

การตรวจ carry หลังบวกคือวิธีที่ CPU จริงใช้บวกเลขที่ใหญ่กว่าขนาด register เช่นบวกเลข 64 บิตบน CPU 32 บิต
