# จำนวนเฉพาะที่น้อยกว่า 50

ให้จอแสดง **จำนวนเฉพาะทุกตัวที่น้อยกว่า 50** เรียงจากน้อยไปมาก: 2, 3, 5, 7, 11, …, 47

## ตะแกรงของเอราทอสเทนีส (Sieve of Eratosthenes)

การหารทีละตัวช้ามากบน CPU ที่ไม่มีคำสั่งหาร วิธีที่เร็วกว่าคือ **ขีดฆ่า**:

1. เตรียมช่องใน RAM สำหรับเลข 2–49 ให้เป็น 0 ทั้งหมด (RAM ไม่ถูกล้างตอน reset ต้องเขียนเอง)
2. สำหรับ p = 2, 3, …, 7 ขีดฆ่าพหุคูณ 2p, 3p, … ที่น้อยกว่า 50 (แค่บวก p ไปเรื่อยๆ ไม่ต้องคูณ)
3. ช่องที่ยังเป็น 0 คือจำนวนเฉพาะ

ใช้ indirect addressing: `STORE [A], B` เขียนลง RAM ที่ address เท่ากับค่าใน A

ทำไมหยุดที่ 7: เลขที่น้อยกว่า 50 ที่ไม่ใช่จำนวนเฉพาะ ต้องมีตัวประกอบที่ไม่เกิน √49 = 7

## ในคอมพิวเตอร์จริง

นี่คือการแลก **หน่วยความจำกับเวลา** ใช้ RAM เพิ่มเพื่อให้เร็วขึ้นมาก เป็นหลักคิดที่ใช้ทั่วไปในการออกแบบโปรแกรม
