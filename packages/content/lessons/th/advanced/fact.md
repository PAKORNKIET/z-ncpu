# แฟกทอเรียลด้วย recursion

สวิตช์คือ n (0–5) ให้จอแสดง **n!** เช่น 5! = 5 × 4 × 3 × 2 × 1 = 120

ด่านนี้ให้ลองเขียนแบบ **เรียกตัวเอง (recursion)**: ฟังก์ชัน `fact` คำนวณ n! จาก n × (n − 1)! โดยเรียก `CALL fact` ตัวเองด้วย n − 1 จนถึง 0! = 1! = 1

## stack ทำให้เรียกตัวเองได้

ทุกครั้งที่ `CALL` CPU เก็บ address ที่ต้องกลับไว้บน stack และแต่ละชั้นของการเรียกต้องจำ n ของตัวเองไว้ด้วย (`PUSH` ก่อนเรียก แล้ว `POP` หลังกลับมา) ชั้นที่ลึกที่สุดคืนค่าก่อน แล้วไล่คืนกลับขึ้นมาทีละชั้น

เปิดหน้าคอมพิวเตอร์แล้วรันทีละคำสั่ง ดู SP ลดลงตอนเรียกลึกลงไป และเพิ่มขึ้นตอนกลับ

## ในคอมพิวเตอร์จริง

stack overflow คือตอนที่เรียกตัวเองลึกจน stack ล้นพื้นที่ที่จองไว้ ชื่อเว็บถามตอบโปรแกรมที่ดังที่สุดก็มาจากข้อผิดพลาดนี้
