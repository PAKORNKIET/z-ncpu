# ตารางจำนวนวันในเดือน

สวิตช์คือเลขเดือน (1–12) ให้จอแสดง **จำนวนวันในเดือนนั้น** (ปีที่ไม่ใช่อธิกสุรทิน เดือน 2 มี 28 วัน) ถ้าเลขเดือนไม่ถูกต้อง (0 หรือ 13 ขึ้นไป) ให้แสดง **0**

## ตารางค้นหา (lookup table)

แทนที่จะเขียน if หลายสิบชั้น ให้เก็บคำตอบไว้ในตาราง แล้วใช้เลขเดือนเป็น address

- `RAM[0x20 + 1] = 31` (มกราคม)
- `RAM[0x20 + 2] = 28` (กุมภาพันธ์)
- … ไปจนถึง `RAM[0x20 + 12] = 31`

`LOAD B, [A]` อ่าน RAM ที่ address เท่ากับค่าใน register A (indirect addressing) จึงอ่านช่องไหนก็ได้ตามค่าที่คำนวณมา

Z8 แยกโปรแกรม (ROM) กับข้อมูล (RAM) ออกจากกัน ตารางจึงต้องเขียนลง RAM เองตอนเริ่มโปรแกรม ลองหาวิธีที่ใช้คำสั่งน้อยที่สุด

## ในคอมพิวเตอร์จริง

ตารางค้นหาใช้ทุกที่: แปลงรหัสตัวอักษรเป็นรูปบนจอ ปรับสีภาพ หรือเก็บค่า sin ที่คำนวณไว้ล่วงหน้าในเกมเก่าๆ
