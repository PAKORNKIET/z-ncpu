# 8-bit Adder

Z8 is an 8-bit CPU, so it must add 8-bit numbers: sum = a + b + cin with overflow on cout. Configure a splitter to split 8 bits into 2 parts of 4 bits (select it and use the right panel) and reuse your 4-bit Adder. Inputs total 17 bits, so the test uses edge cases plus 2,000 seeded random cases.
