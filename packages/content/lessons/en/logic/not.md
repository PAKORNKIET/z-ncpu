# Build NOT

**NOT** has one input and one output: 0 becomes 1, and 1 becomes 0.

You only have a **NAND gate**, which outputs 0 only when both inputs are 1.

Wire NAND so it behaves like NOT, then press **Test**. Once it passes, NOT joins your toolbox for later levels.

In a real computer, NOT is everywhere — for example, a **subtractor** inverts the bits of one operand before adding. You will build one in Chapter 2.
