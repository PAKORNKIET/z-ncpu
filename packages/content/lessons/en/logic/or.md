# Build OR

OR outputs 1 when **at least one** input is 1, and 0 only when both inputs are 0.

| a | b | y |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0 | 1 |
| 0 | 1 | 1 |
| 1 | 1 | 1 |

Available: NAND, plus the NOT and AND you built. Compare the OR table with the NAND table: what changes if you invert something first?
