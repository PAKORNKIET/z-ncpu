# Build the Z8 CPU

Everything you built since the first NAND comes together here. Z8 is a single-cycle CPU: in one clock tick the PC fetches a 16-bit instruction from ROM256 (programmed by the panel wired to `prog`), the Decoder produces control signals, the register file reads rd (x) and rs (y), a MUX picks src (y or the 8-bit constant), the ALU computes, memory is addressed by src, SP or SP−1 (addresses ≥ 0xF0 are I/O, not RAM), and on the rising edge every register (rd, flags, RAM, SP, PC) updates at once.

Pins: prog (4,096), reset, clk, sw/btn/key (read at 0xF8–0xFA); outputs out and leds (written at 0xF0, 0xF1), seg (value at 0xF2 through your 7-segment decoder), and debug pins pc, a, b, c, d, sp, flags (Z<<2 | C<<1 | N) and halt.

The test loads programs, resets the CPU and compares every debug pin with a reference emulator on every cycle, reporting the first cycle, instruction and pin that differ. I/O outputs are only compared after the program first writes them.
