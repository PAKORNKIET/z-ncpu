## หลักการ
ALU **คำนวณทุกงานพร้อมกัน** แล้วใช้ op เลือกว่าจะเอาผลไหน (วงจรไม่มี "if" แต่มีตัวเลือก)

| op | งาน | วิธีทำ |
| --- | --- | --- |
| 0 | ADD | ADD8(a, b, cin = 0) |
| 1, 7 | SUB, CMP | ADD8(a, NOT b, cin = 1) |
| 2, 3, 4 | AND, OR, XOR | ชิ้น 8 บิตของบท 3 |
| 5 | NOT a | NOT8(a) |
| 6 | 0 | ค่าคงที่ 0 ทุกบิต |

## ต่ออย่างไร
- ต่อทุกงานจาก a และ b แล้วเข้า d0–d7 ของ SEL8 โดย op เป็น sel แล้วไปที่ **y**
- **z**: ผลเข้า ZERO8
- **n**: บิต 7 ของผล (บิตเครื่องหมาย)
- **c**: ต้นไม้ MUX ที่ใช้ op เลือกตัวทด: op 0 ใช้ cout ของตัวบวก, op 1 และ 7 ใช้ cout ของตัวลบ, op อื่นเป็น 0

## ทำไมต้องแบบนี้
งานทั้งหมดใช้เวลาเท่ากันเพราะคำนวณพร้อมกันอยู่แล้ว การเลือกตอนท้ายจึงง่ายและเร็ว นี่คือวิธีที่ ALU ของ CPU จริงทำงาน flags คำนวณจากผลที่ถูกเลือกแล้ว จึงใช้ได้กับทุกงาน
