## หลักการ
CPU ไม่มีคำสั่งคูณ จึงคูณด้วย **การบวกซ้ำ**: a × b = b + b + … (a ครั้ง) ส่วนการแยกตัวเลขสองตัวจากสวิตช์ใช้ **การลบซ้ำ** (หารด้วย 16)

## โปรแกรมทำอะไร
- อ่านสวิตช์ลง A แล้วลบ 16 ไปเรื่อยๆ จนน้อยกว่า 16 นับว่าลบได้กี่ครั้งลง C ได้ C = a (4 บิตบน) และ A ที่เหลือ = b (4 บิตล่าง)
- D = 0 ถ้า a = 0 ไปแสดงผลเลย
- วน a ครั้ง: D = D + b
- แสดง D

## ทำไมต้องแบบนี้
ต้องเช็ก a = 0 ก่อนเข้าลูป เพราะลูปลบ C ก่อนแล้วค่อยดู Z ถ้า C เริ่มที่ 0 จะกลายเป็น 255 แล้ววน 255 รอบ ผลสูงสุด 15 × 15 = 225 จึงไม่ล้น 8 บิต
