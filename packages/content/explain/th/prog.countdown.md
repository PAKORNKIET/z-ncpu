## หลักการ
ลูป = กระโดดกลับไปทำซ้ำ และใช้ **flags** ตัดสินใจว่าจะออกจากลูปเมื่อไร

## โปรแกรมทำอะไร
- เริ่ม A = 5
- loop: แสดง A แล้วลบ 1
- ถ้าผลติดลบ (flag N = 1 คือ 0 − 1 = 255 ซึ่งบิตบนสุดเป็น 1) กระโดดไป done
- ไม่งั้นกลับไป loop

## ทำไมต้องแบบนี้
แสดงก่อนลบ จอจึงขึ้น 5, 4, 3, 2, 1, 0 ครบ แล้วพอลบจาก 0 จะได้ค่าติดลบเป็นสัญญาณจบ ใช้ JZ แทนไม่ได้ เพราะตอน A กลายเป็น 0 ยังไม่ได้แสดง 0
