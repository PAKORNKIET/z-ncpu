## หลักการ
ตัวนับคือ register ที่ทุกจังหวะรับค่า "ตัวเอง + 1" และกลับเป็น 0 เมื่อ reset

## ต่ออย่างไร
- reg8: load = **ค่าคงที่ 1** (รับค่าใหม่ทุกจังหวะ) และ clk ของวงจร
- out ของ reg8 เข้า INC8
- MUX8: a = ผลของ INC8, b = 0 (ค่าคงที่ 0 ทั้ง 8 บิต), sel = **reset** แล้วเข้า in ของ reg8
- out ของ reg8 ไปที่ **q**

## ทำไมต้องแบบนี้
วงจรวนกลับผ่าน register ไม่มีปัญหา เพราะ register เปลี่ยนแค่ตอนขอบนาฬิกา ค่า q + 1 จึงไม่วิ่งวนไม่รู้จบ reset ใช้ MUX เลือก 0 แทนจึงมีผลในจังหวะถัดไป (reset แบบ synchronous)
