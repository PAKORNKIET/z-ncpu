## หลักการ
Stack Pointer เก็บ address ยอด stack และเลือกค่าถัดไปตาม op: 0 = คงเดิม, 1 = ลด 1 (PUSH, CALL), 2 = เพิ่ม 1 (POP, RET) และ reset = 0xF0

## ต่ออย่างไร
- reg8 เก็บ SP โดย load = ค่าคงที่ 1
- SP − 1: ADD8 บวก SP กับ 11111111 (ซึ่งคือ −1) ผลนี้ออกขา **down** ด้วย (address ที่ PUSH จะเขียน)
- SP + 1: INC8
- SEL4: d0 = SP, d1 = SP − 1, d2 = SP + 1, d3 = SP โดย sel = op
- MUX8: reset เลือก 0xF0 (บิต 4–7 เป็น 1) แทน แล้วเข้า in ของ reg8

## ทำไมต้องแบบนี้
ลดหนึ่งด้วยการบวก −1 ใช้ตัวบวกเดิมได้เลย stack โตลงล่างจาก 0xF0 จึงไม่ชนช่อง I/O ที่ 0xF0–0xFF
