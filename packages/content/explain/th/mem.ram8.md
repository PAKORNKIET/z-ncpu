## หลักการ
RAM คือ register หลายตัวที่มี **address** บอกว่าใช้ช่องไหน
- **เขียน**: ส่ง load ไปที่ register ตาม address ช่องเดียว
- **อ่าน**: เลือกขาออกของ register ตาม address

## ต่ออย่างไร
- DEMUX8: in = **load**, sel = addr แล้วขาออก o0–o7 เข้า load ของ reg8 แต่ละตัว
- reg8 ทั้ง 8 ตัวรับ **in** และ **clk** เส้นเดียวกัน
- SEL8: d0–d7 = out ของ reg8 แต่ละตัว, sel = addr แล้วไปที่ **out**

## ทำไมต้องแบบนี้
ข้อมูลที่จะเขียนส่งไปทุกช่องได้เลย เพราะช่องที่ load = 0 จะไม่รับ ส่วน DEMUX ทำให้มีแค่ช่องเดียวที่ load = 1
