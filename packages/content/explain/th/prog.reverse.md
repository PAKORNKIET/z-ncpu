## หลักการ
**Stack** เป็นแบบเข้าทีหลังออกก่อน (LIFO): PUSH ค่าตามลำดับแล้ว POP ออก จะได้ลำดับกลับกันเสมอ

## โปรแกรมทำอะไร
- อ่าน x จากสวิตช์ แล้ว PUSH x, x + 1, x + 2
- POP ทีละตัวแล้วแสดง ได้ x + 2, x + 1, x

## ทำไมต้องแบบนี้
SP เริ่มที่ 0xF0 PUSH ลด SP แล้วเขียน ส่วน POP อ่านแล้วเพิ่ม SP ค่าที่ใส่ทีหลังจึงอยู่ "บนสุด" และออกมาก่อน หลักเดียวกันนี้ใช้จำที่กลับของ CALL
