## หลักการ
ตรวจทีละบิตด้วยการ **เลื่อนซ้าย**: ADD A, A คือ A × 2 ซึ่งดันบิตบนสุดออกไปเป็น **flag C**

## โปรแกรมทำอะไร
- อ่านสวิตช์ลง A (และแสดงบน LED ให้เห็น)
- B = 0 นับบิต, C = 8 นับรอบ
- loop: ADD A, A ถ้า C = 1 (บิตที่หลุดออกเป็น 1) ให้ B + 1
- C − 1 วนจนครบ 8 รอบ แล้วแสดง B

## ทำไมต้องแบบนี้
Z8 ไม่มีคำสั่งเลื่อนบิตหรือทดสอบบิต แต่ตัวบวกมี flag C อยู่แล้ว การบวกตัวเองจึงเป็นการเลื่อนซ้ายที่ได้บิตออกมาฟรี (ในด่านโบนัสคุณจะเพิ่มคำสั่ง SHR เอง)
