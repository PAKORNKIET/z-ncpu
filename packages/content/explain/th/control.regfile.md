## หลักการ
ชุด register = RAM ขนาดเล็ก 4 ช่อง (A–D) แต่ **อ่านได้สองช่องพร้อมกัน** (rd และ rs) เพราะคำสั่งอย่าง ADD A, B ต้องใช้ทั้งสองค่าในจังหวะเดียว

## ต่ออย่างไร
- DEMUX4: in = write, sel = rd ส่งคำสั่งเขียนไปที่ reg8 ตัวเดียว
- reset: OR เข้า load ของทุกตัว และ MUX8 เลือก 0 แทน in ทุก register จึงเป็น 0 พร้อมกัน
- SEL4 ตัวแรก: sel = rd ได้ **x** และ SEL4 ตัวที่สอง: sel = rs ได้ **y**
- out ของแต่ละตัวต่อออก **a–d** ไว้ให้ดีบัก

## ทำไมต้องแบบนี้
ตัวเลือกสองตัวแยกกัน ทำให้อ่านสองช่องได้อิสระ ส่วนการเขียนมีทางเดียว CPU จริงก็เรียก register file แบบนี้ว่า "2 read ports, 1 write port"
