## หลักการ
**ตะแกรงของเอราทอสเทนีส (Sieve of Eratosthenes)**: แทนที่จะลองหารทุกตัว ให้ขีดฆ่าพหุคูณของแต่ละตัวทิ้ง ตัวที่เหลือคือจำนวนเฉพาะ ใช้ RAM[n] เป็นช่องเครื่องหมายของเลข n

## โปรแกรมทำอะไร
- ล้าง RAM[2]–RAM[49] เป็น 0 (ยังไม่ถูกขีด)
- p = 2 ถึง 7: ขีด 2p, 3p, … ที่น้อยกว่า 50 (เขียนค่า p ลงไป ซึ่งไม่ใช่ 0)
- ไล่ n = 2 ถึง 49 ช่องที่ยังเป็น 0 คือจำนวนเฉพาะ แสดง n

## ทำไมต้องแบบนี้
RAM ไม่ถูกล้างตอน reset จึงต้องล้างเองก่อน ขีดแค่ p ≤ 7 ก็พอ เพราะเลขประกอบที่น้อยกว่า 50 ต้องมีตัวประกอบไม่เกิน √49 = 7 Z8 ไม่มีคำสั่งหาร วิธีนี้ใช้แค่การบวกจึงเหมาะมาก
