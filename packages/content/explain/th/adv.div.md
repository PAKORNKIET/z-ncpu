## หลักการ
หาร = **ลบซ้ำ**: ลบตัวหารออกไปเรื่อยๆ ตราบที่ยังลบได้ จำนวนครั้งคือผลหาร ส่วนที่เหลือคือเศษ

## โปรแกรมทำอะไร
- A = ตัวตั้ง (สวิตช์), B = ตัวหาร (คีย์บอร์ด), C = 0
- loop: CMP A, B ถ้า C = 1 (A ≥ B) ลบ A − B แล้ว C + 1 วนต่อ
- ไม่งั้นจบ: แสดง C (ผลหาร) บนจอ และ A (เศษ) บน LED

## ทำไมต้องแบบนี้
flag C ของ CMP บอก "A ≥ B" แบบไม่มีเครื่องหมายได้ถูกต้องทุกค่า 0–255 ถ้าตัวหารเป็น 0 ลูปจะไม่จบ (โจทย์ไม่ทดสอบกรณีนั้น)
