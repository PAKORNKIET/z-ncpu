## หลักการ
ความจำเริ่มจาก **การป้อนกลับ (feedback)**: NAND สองตัวที่ต่อขาออกของตัวหนึ่งไปเป็นขาเข้าของอีกตัวไขว้กัน จะค้างอยู่ได้สองสถานะ (q = 0 หรือ q = 1) และอยู่อย่างนั้นจนกว่าจะมีคนมาเปลี่ยน

## ต่ออย่างไร
- nand1 = NOT s และ nand2 = NOT r (กลับค่าก่อน เพราะแกนข้างในทำงานตอนขาเข้าเป็น 0)
- nand3: NOT s กับขาออกของ nand4 แล้วไปที่ **q**
- nand4: NOT r กับขาออกของ nand3 (ไขว้กัน)

## ทำไมต้องแบบนี้
- s = 1: NOT s = 0 บังคับให้ nand3 = 1 ได้ q = 1
- r = 1: NOT r = 0 บังคับให้ nand4 = 1 แล้ว nand3 ได้ 1 กับ 1 จึงเป็น 0 ได้ q = 0
- s = r = 0: ขาเข้าด้านนอกเป็น 1 ทั้งคู่ NAND แต่ละตัวจึงแค่กลับค่าของอีกตัว ค่าเดิมเลยวนค้างอยู่
