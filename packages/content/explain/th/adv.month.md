## หลักการ
**ตารางค้นหา (lookup table)**: เก็บคำตอบทั้งหมดไว้ใน RAM แล้วใช้ **address = ฐาน + เดือน** อ่านคำตอบทีเดียว แทนการเขียน if หลายชั้น

## โปรแกรมทำอะไร
- ใส่ 31 ลง RAM[0x21]–RAM[0x2C] ก่อน (เดือน 1–12)
- แก้เดือน 4, 6, 9, 11 เป็น 30 และเดือน 2 เป็น 28
- อ่านเดือนจากสวิตช์ ถ้า ≥ 13 หรือ = 0 แสดง 0
- ไม่งั้น A = 0x20 + เดือน แล้ว LOAD B, [A] (อ่านแบบใช้ register เป็น address) แล้วแสดง B

## ทำไมต้องแบบนี้
เดือนส่วนใหญ่มี 31 วัน การเติมทั้งตารางแล้วแก้เฉพาะเดือนที่ต่างจึงสั้นที่สุด ต้องตรวจขอบเขตก่อนอ่านเสมอ ไม่งั้นจะอ่านช่องนอกตาราง CPU จริงใช้ตารางแบบนี้ทุกที่ ตั้งแต่ฟอนต์จนถึง jump table
