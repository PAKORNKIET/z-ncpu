## หลักการ
XOR ให้ 1 เมื่อ a กับ b **ต่างกัน** เคล็ดคือหา NAND(a, b) ไว้ก่อน (เรียกว่า n) แล้วใช้ n ซ้ำสองที่

- **n = NAND(a, b)** เป็น 0 เฉพาะตอน a = b = 1
- **p = NAND(a, n)** เป็น 0 เฉพาะตอน a = 1 และ b = 0
- **q = NAND(b, n)** เป็น 0 เฉพาะตอน a = 0 และ b = 1
- **y = NAND(p, q)** เป็น 1 เมื่อ p หรือ q เป็น 0 คือเมื่อ a กับ b ต่างกัน

## ต่ออย่างไร
- nand1: a, b
- nand2: a, ขาออกของ nand1
- nand3: b, ขาออกของ nand1
- nand4: ขาออกของ nand2 และ nand3 แล้วไปที่ **y**

## ทำไมต้องแบบนี้
ถ้าต่อตรงสูตร (a AND NOT b) OR (NOT a AND b) จะใช้ NAND มากกว่าเยอะ การใช้ n ร่วมกันสองที่ทำให้เหลือ 4 ตัว ซึ่งเป็นค่าที่น้อยที่สุด
