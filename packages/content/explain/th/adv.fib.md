## หลักการ
เก็บแค่ **สองตัวล่าสุด** ก็สร้างลำดับต่อได้ตลอด และใช้ **flag C** ของการบวกบอกว่าเกิน 255 แล้ว

## โปรแกรมทำอะไร
- A = 1 (ตัวปัจจุบัน), B = 1 (ตัวก่อนหน้า)
- loop: แสดง A แล้ว C = A + B
- ถ้า C ทด (เกิน 255) จบ
- ไม่งั้นเลื่อนหน้าต่าง: B = A แล้ว A = C วนต่อ

## ทำไมต้องแบบนี้
ต้องคำนวณลง C ก่อน เพราะถ้า ADD A, B ตรงๆ ค่าเดิมของ A จะหายไปก่อนจะย้ายไปเป็น B จอนับเฉพาะตอนค่าเปลี่ยน เลข 1 ตัวที่สองจึงไม่ขึ้นซ้ำ
